# 임시 코드 정리 규칙

작업 중 만든 **테스트·검증·디버깅용 산출물은 작업 완료 시 전부 삭제**합니다.
"나중에 쓸지도 모른다"는 이유로 남기지 않습니다.

## 삭제 대상

### 코드

- `console.log` / `console.warn` / `debugger` — 디버깅용으로 넣은 것 전부.
  단, `config.debug` 플래그로 감싼 `[pick-option]` prefix 로그는 정식 기능이므로 유지합니다.
- 동작 확인용 임시 변수, 사용되지 않게 된 함수·상수.
- 실험하다 남은 대체 구현(주석 처리된 이전 버전 포함).
- 임시로 넣은 `window.__debug*`, 전역 노출, 테스트용 hook.
- 하드코딩한 임시 값(고정된 개수, 더미 가격, 임시 셀렉터).

### 파일

- 스크래치 스크립트: `_repro.js`, `_dbg.js`, `_bal.js`, `_old.js`, `test/_*.js` 등
  프로젝트 루트나 `test/` 에 만든 일회성 파일.
- 임시 픽스처·복사본(`*.bak`, `*.old`, `*-copy.*`, `/tmp` 에 만든 사본).
- 확인용으로 만든 미리보기 HTML.

임시 파일은 가능하면 처음부터 스크래치패드 디렉터리에 만들고 저장소에 두지 않습니다.

### 주석

- `// TODO: 확인용`, `// 임시`, `// 나중에 지울 것`, `// 여기까지 확인함` 류.
- 코드를 그대로 옮겨 쓴 설명 주석(`// i를 1 증가`).
- 작업 로그성 주석(`// 2026-07-24 수정`) — 이런 정보는 커밋 메시지에 둡니다.

## 유지 대상 (삭제하지 말 것)

- `test/` 아래의 **정식 자동 테스트** (`test.js`, `test-textbutton.js`,
  `test-basicskin.js`, `test-page.js`)와 그 픽스처(`fixture_*.html`).
  기능을 바꿨다면 여기 테스트를 **갱신**하고, 삭제하지 않습니다.
- [js/option_config.js](../../js/option_config.js) 의 설정 설명 주석 —
  다른 작업자를 위한 문서입니다.
- 카페24 스킨 템플릿 안의 `<!-- ★CAFE24 ... -->` 주석과 카페24가 참조하는
  주석(예: "상품이 추가되는 영역"). 이건 삭제하면 기능이 깨집니다.
- "왜 이렇게 했는지"를 설명하는 주석(예: 기본 스킨의 다중 `<tbody>` 대응 사유).

## 완료 전 체크

작업을 마쳤다고 보고하기 전에 확인합니다:

1. `git status` — 의도하지 않은 새 파일이 없는가?
2. `git diff` — 디버그 로그·임시 주석이 섞이지 않았는가?
3. 정식 테스트 4종이 통과하는가? (실패하면 결과를 그대로 보고)
4. 민감 정보(계정·API 키·몰 ID)가 diff에 없는가?
